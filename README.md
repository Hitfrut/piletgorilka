# Контроллер для пеллетной горелки на Arduino Nano

Это базовый пример прошивки для управления пеллетной горелкой на Arduino Nano.
Скетч реализует простую конечную автоматику: **ожидание → розжиг → работа → продувка → авария**.

## Состав пеллетной факельной горелки (что управляем)

### 🔥 Исполнительные механизмы

- Шнек подачи пеллет (ON/OFF или импульсный режим).
- Вентилятор наддува (PWM).
- ТЭН розжига (реле).
- Подвижные колосники (мотор/реле, циклически).
- Насос отопления (реле).

### 📡 Датчики

- Термопара (тип K) — температура факела (MAX6675).
- Температура подачи (DS18B20) pin D12.
- Температура обратки (DS18B20) pin D12.
- Комнатный термостат (сухой контакт).
- Фотодатчик пламени / наличия пеллет (фоторезистор / фотодиод / ИК).

## Возможности

- Управление вентилятором, шнеком, розжигом, колосниками и насосом.
- Таймеры розжига, стабилизации, продувки и очистки.
- Контроль температуры подачи/обратки с DS18B20 и факела с термопары.
- Запрос тепла от комнатного термостата.
- Контроль наличия пеллет/пламени по фотодатчику.
- Меню управления и настройки на LCD 20x4.
- Защита по перегреву и по погасшему пламени.

## Подключение

- D12 — датчики температуры DS18B20 (подача/обратка, линия данных + подтяжка 4.7k к 5V).
- D8/D9 — энкодер (A/B, линии с подтяжкой).
- D4 — кнопка энкодера (замыкание на GND).
- A3 — комнатный термостат (замыкание на GND).
- A7 — фотодатчик пеллет (аналоговый вход).
- D5 — вентилятор (PWM).
- D6 — шнек (реле/модуль MOSFET).
- D7 — розжиг (реле/модуль MOSFET).
- A2 — привод подвижных колосников (реле/модуль MOSFET).
- A1 — насос отопления (реле/модуль MOSFET).
- Термопара MAX6675: SCK=D13, CS=D10, SO=D11.
- LCD 20x4 (I2C): SDA=A4, SCL=A5, адрес по умолчанию 0x27.

## Настройка

Основные параметры задаются в начале файла `pellet_burner_controller.ino` или через меню:

- `targetTempC` — целевая температура.
- `maxTempC` — аварийный перегрев.
- `minFlameTempC` — минимальная температура, ниже которой считается, что пламя погасло.
- `maxExhaustTempC` — ограничение температуры дымовых газов.
- `maxFlameTempC` / `minFlameThermoC` — пределы температуры факела по термопаре.
- `pumpOnTempC` — включение насоса по температуре подачи.
- `ignitionTimeMs` — максимальная длительность розжига.
- `startTimeMs` / `stabilizationTimeMs` — подготовка и стабилизация.
- `cooldownTimeMs` — продувка после остановки.
- `augerOnMs` / `augerOffMs` — цикл подачи топлива.
- `ignitionAugerOnMs` / `ignitionAugerOffMs` — подача пеллет на розжиге.
- `grateCycleMs` / `grateOnMs` — цикл работы колосников.
- `pelletMissingTimeoutMs` — таймаут отсутствия пеллет по фотодатчику.
- `flameTimeoutMs` — таймаут отсутствия пламени.
- `fanMinPwm` / `fanMaxPwm` / `ignitionFanPwm` — уставки ШИМ вентилятора.
- `modulationBandC` — зона модуляции.

## Режимы работы горелки (состояния автоматики)

- **OFF** — ожидание.
- **START** — подготовка.
- **IGNITION** — розжиг.
- **STABILIZATION** — выход на режим.
- **WORK** — работа.
- **MODULATION** — снижение мощности.
- **CLEANING** — очистка колосников.
- **STOP** — останов и продувка.
- **ALARM** — авария.

## Логика работы (упрощённо)

### ▶️ Пуск

Проверка:

- есть запрос от термостата;
- температура подачи ниже заданной.

Включается:

- вентилятор (низкий PWM);
- подача пеллет (коротко);
- ТЭН розжига.

Ожидаем:

- рост температуры термопары;
- сигнал с фотодатчика.

Если нет пламени за `flameTimeoutMs` → **ALARM**.

### 🔥 Работа

- Вентилятор — PWM.
- Шнек — циклы (например 1.2 сек ON / 5 сек OFF).
- Колосники — раз в N минут.
- Насос — при температуре подачи выше `pumpOnTempC`.

### 📉 Модуляция

При приближении к целевой температуре:

- уменьшаем PWM вентилятора;
- уменьшаем подачу пеллет.

### ⛔ Останов

- отключаем подачу пеллет;
- продувка вентилятором;
- очистка колосников;
- переход в **OFF**.

## Меню

- В состоянии ожидания на дисплее показывается статус и температура.
- Короткое нажатие на энкодер открывает меню настройки и переключает пункты.
- Поворот энкодера изменяет значение.
- Долгое нажатие (≈1.5 сек) — останов/выход в статусный экран.

## Важно

Этот пример — стартовая точка. Перед использованием в реальной установке:

- Проверьте электрическую безопасность и развязку силовой части.
- Добавьте датчики тяги/дымовых газов, контроля пламени и аварийные цепи.
- Проведите испытания и калибровку под вашу горелку.
