# Контроллер для пеллетной горелки на Arduino Nano

Это базовый пример прошивки для управления пеллетной горелкой на Arduino Nano.
Скетч реализует простую конечную автоматику: **ожидание → розжиг → работа → продувка → авария**.

## Возможности

- Управление вентилятором, шнеком и розжигом.
- Таймер розжига и продувки.
- Контроль температуры подачи/обратки с цифровыми датчиками DS18B20 (Dallas).
- Контроль температуры дымовых газов термопарой (MAX6675).
- Комнатный термостат для запроса тепла.
- Фотодатчик для определения наличия пеллет.
- Управление подвижными колосниками.
- Меню управления и настройки на LCD 20x4.
- Защита по перегреву и по погасшему пламени.

## Подключение

- D12 — датчики температуры DS18B20 (подача/обратка, линия данных + подтяжка 4.7k к 5V).
- D2 — кнопка старт (замыкание на GND).
- D3 — кнопка стоп (замыкание на GND).
- D8/D9 — энкодер (A/B, линии с подтяжкой).
- D4 — кнопка энкодера (замыкание на GND).
- A3 — комнатный термостат (замыкание на GND).
- A7 — фотодатчик пеллет (аналоговый вход).
- D5 — вентилятор (PWM).
- D6 — шнек (реле/модуль MOSFET).
- D7 — розжиг (реле/модуль MOSFET).
- A2 — привод подвижных колосников (реле/модуль MOSFET).
- Термопара MAX6675: SCK=D13, CS=D10, SO=D11.
- LCD 20x4 (I2C): SDA=A4, SCL=A5, адрес по умолчанию 0x27.

## Настройка

Основные параметры задаются в начале файла `pellet_burner_controller.ino` или через меню:

- `targetTempC` — целевая температура.
- `maxTempC` — аварийный перегрев.
- `minFlameTempC` — минимальная температура, ниже которой считается, что пламя погасло.
- `maxExhaustTempC` — ограничение температуры дымовых газов.
- `ignitionTimeMs` — максимальная длительность розжига.
- `cooldownTimeMs` — продувка после остановки.
- `augerOnMs` / `augerOffMs` — цикл подачи топлива.
- `grateCycleMs` / `grateOnMs` — цикл работы колосников.
- `pelletMissingTimeoutMs` — таймаут отсутствия пеллет по фотодатчику.

## Меню

- В состоянии ожидания на дисплее показывается статус и температура.
- Кнопки Start/Stop открывают меню настройки.
- Поворот энкодера изменяет значение, его кнопка переключает пункт меню, Stop выходит в статусный экран.

## Библиотеки

- OneWire
- DallasTemperature
- LiquidCrystal_I2C
- max6675

## Важно

Этот пример — стартовая точка. Перед использованием в реальной установке:

- Проверьте электрическую безопасность и развязку силовой части.
- Добавьте датчики тяги/дымовых газов, контроля пламени и аварийные цепи.
- Проведите испытания и калибровку под вашу горелку.
